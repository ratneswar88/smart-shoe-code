⚡ Power Architecture

LiPo → PowerBoost → 5V → ESP32-S3 (5V pin) → onboard LDO → 3.3V → GY-86

📡 Sensor Bus

I²C shared bus: ESP32-S3 GPIO8 (SDA) / GPIO9 (SCL) → GY-86. Addresses: 0x68 MPU6050, 0x1E HMC5883L, 0x77 MS5611

🔋 Battery Monitor

PowerBoost LBO (low batt, pulled to BAT ≈4V) → voltage divider → ESP32-S3 GPIO5 (ADC-safe, 3.3V logic)

⚠

LBO Level-Shift Critical: The LBO pin is pulled to BAT voltage (3.0–4.2V range). ESP32-S3 GPIO absolute maximum is 3.6V. You must use a voltage divider or level-shifter before connecting LBO to any ESP32-S3 GPIO. Omitting this will damage the MCU over time. See §3 for the exact resistor network.

§03

Critical Sub-Circuits

⚗ LBO Voltage Divider

Scales BAT-level LBO (up to 4.2V) to safe GPIO input (≤2.52V):

LBO_PIN ──┬── R1(100kΩ) ──── GPIO5
            │
            R2(150kΩ)
            │
            GND

V_GPIO = 4.2V × 150k/(100k+150k) = 2.52V ✓
GPIO5 reads LOW when battery <3.2V (LBO fires)
Add 100nF decoupling cap at GPIO5 to GND

🔗 I²C Pull-Up Network

Both SDA and SCL require pull-ups. Place as close to GY-86 as possible:

3V3 ─── R3(4.7kΩ) ─── SDA (GPIO8)
3V3 ─── R4(4.7kΩ) ─── SCL (GPIO9)
                                     

4.7kΩ is standard for 100kHz I²C.
Use 2.2kΩ if running at 400kHz fast-mode.
GY-86 has on-module 4.7kΩ — check bridge resistors
to avoid double pull-up (use 10kΩ external instead).

🔘 Power Enable Switch

SPDT slide switch to control boost output via EN pin:

EN ──── SW1 ──── GND
       (open=ON, closed=OFF)
Route to edge-mounted slide switch
Low-current signal only (~1µA)

⟶ Any tiny SMD slide switch works — EN is signal-level only, not in-line with battery current. Minimal switch rating required.

🧲 Decoupling Capacitors

Place at each power pin as close to IC as possible:

LocationCapValue
ESP32-S3 VIN (5V)C1100µF electrolytic + 100nF ceramic
ESP32-S3 3V3 outputC210µF tantalum + 100nF ceramic
GY-86 VCCC310µF + 100nF ceramic
PowerBoost 5V railC4100µF + 100nF (already onboard)
LBO divider GPIO5C5100nF ceramic

GY-86 I²C Note: The GY-86 module may already have 4.7kΩ pull-up resistors soldered onboard. Before adding external pull-ups (R3/R4), check the module — running two 4.7kΩ resistors in parallel gives 2.35kΩ which may be too strong and cause noise. If the GY-86 already has pull-ups, use 10kΩ external resistors only as a fallback, or bridge/remove the onboard ones.

📡

RF Antenna Clearance: The ESP32-S3 Zero has a PCB ceramic antenna on one end. Do not route any ground planes, copper pours, or tall components within 3–5mm of the antenna area. Place the ESP32-S3 Zero so the antenna end faces the edge or open area of the carrier PCB. This is critical for BLE/WiFi range in your smart shoe application.

🧲

GY-86 IMU Placement: Keep the GY-86 away from the PowerBoost 500C (TPS61090 switching at 700kHz) and any large electrolytic capacitors. Magnetic interference from boost converter switching can corrupt HMC5883L magnetometer readings. Minimum separation of 20mm is recommended. Consider adding a ferrite bead on the 3V3 supply line feeding GY-86.

Firmware Integration Notes

⚙ I²C Initialization (ESP-IDF / Arduino)
// Arduino / ESP-IDF I2C config
#define I2C_SDA 8 // GPIO8
#define I2C_SCL 9 // GPIO9
#define I2C_FREQ 400000 // 400kHz

Wire.begin(I2C_SDA, I2C_SCL);
Wire.setClock(I2C_FREQ);

// I2C Addresses:
// MPU6050 → 0x68 (AD0 low)
// HMC5883L → 0x1E
// MS5611 → 0x77 (CSB low)
🔋 LBO Battery Monitor
#define LBO_PIN 5 // GPIO5

// LBO is ACTIVE LOW when battery
// drops below 3.2V
pinMode(LBO_PIN, INPUT_PULLUP);

if (digitalRead(LBO_PIN) == LOW) {
  // Low battery detected!
  // Alert BLE characteristic
  // or initiate safe shutdown
}
📡 GY-86 Key I²C Addresses
SensorI²C AddrRole
MPU60500x686-axis IMU (accel + gyro)
HMC5883L0x1E3-axis magnetometer
MS56110x77Barometric pressure + altitude

MPU6050 has a passthrough I²C master that can access HMC5883L internally — or bypass this and address all three independently from ESP32-S3.

⚡ Power Sequencing
  1. SW1 open → EN floats HIGH → PowerBoost outputs 5V
  2. ESP32-S3 receives 5V on its 5V pin → onboard LDO powers up → 3.3V available
  3. GY-86 VCC_IN receives 3.3V → sensors initialize
  4. ESP32-S3 firmware: init Wire → scan bus → start sensor fusion
  5. Monitor GPIO5 for LBO event → handle gracefully
§08

Pre-Layout Design Rules Checklist

✅ Power & Safety
  • LBO voltage divider fitted (R1=100kΩ, R2=150kΩ)
  • 100nF ceramic cap on GPIO5 (LBO input)
  • 100µF bulk cap on 5V rail
  • 10µF bulk cap on 3.3V rail
  • Ferrite bead on 3.3V → GY-86 VCC line
  • Power switch on EN pin (NOT in battery path)
  • Battery polarity protection / check JST orientation
  • 5V trace width ≥ 1.5mm end-to-end
✅ Signal Integrity & RF
  • I²C pull-ups near GY-86 (check for onboard resistors first)
  • SDA / SCL traces kept short and matched
  • ESP32-S3 antenna area clear of copper flood
  • GY-86 ≥ 20mm from PowerBoost switching converter
  • GND copper pour on bottom layer (4-layer: L2 dedicated)
  • No 5V traces running under GY-86 module
  • Test pads on SDA, SCL, 5V, 3V3, GND for debugging
  • 3D clearance for LiPo battery under or beside PCB
