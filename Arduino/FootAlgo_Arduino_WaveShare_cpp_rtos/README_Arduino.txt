Arduino — Waveshare ESP32-S3 Zero
- Core: Arduino-ESP32 2.0.14+
- Lib: NimBLE-Arduino (by h2zero)
- Tools:
  - Board: ESP32S3 Dev Module (if Waveshare profile not present)
  - USB CDC On Boot: Enabled
  - USB Mode: CDC and JTAG
  - Upload Mode: USB-OTG (or UART)
- I2C: SDA=8, SCL=9 (Config.h)
- Open FootAlgo_Arduino_WaveShare.ino and Upload.
