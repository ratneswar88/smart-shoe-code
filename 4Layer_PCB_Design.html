Via Strategy: Power planes (L3) are accessed from both sides via PTH vias. The 5V net travels: PB (L4) → via → L3 power pour → via → ESP32 (L1). GND uses L2 as the reference plane — all GND pads connect to L2 by the nearest via. This eliminates long GND return paths and reduces EMI from the TPS61090 switching at 700kHz.
